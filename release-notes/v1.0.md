# Jerry Notes v1.0 Release Notes

发布日期：2026-03-24

## 版本概览
Jerry Notes v1.0 完成了内容发布、内部资料访问、文章阅读、PDF 导出、PC/移动端展示等核心能力的一轮收口。这个版本的重点不是增加复杂功能，而是把“小站作为稳定工作台”的基础体验打牢。

## 本次版本重点

### 1. 经营例会材料发布链路跑通
- 基于周计划重整出经营例会汇报材料。
- 支持持续小步修改并即时发布到小站。
- 同步完成排序、展示与导出链路联调。

### 2. 文章阅读与导出体验完成首轮闭环
- 文章页支持直接导出为 PDF。
- 打印时只保留当前文章正文。
- 导出标题与文章标题保持一致。

### 3. 首页卡片与站点信息结构优化
- 卡片更紧凑，内部标签进入标题行。
- 去掉卡片间虚线，整体观感更清爽。
- PC 端头部操作区完成重新整理。

### 4. 移动端体验集中修复
- 修复首屏主题闪动、筛选菜单闪动。
- 修复抬头区与内容区不对齐。
- 修复内容溢出与筛选面板异常。
- 降低登录前后头部跳动。

## 本版本包含的能力
- 文章列表与筛选
- 内部 / 公开文章展示
- 文章详情阅读
- PDF 导出
- 站点主题切换
- 基础飞书登录入口
- 移动端与 PC 端自适应展示

## 已知待办
- 飞书登录线上 Functions 路由仍需继续排查与修复。
- 首页与移动端仍可继续做视觉细节收口。
