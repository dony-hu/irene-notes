# 爆款产品从零到一上市管理流程

## 一、项目启动前置条件

在启动立项前，必须完成：

1. **价值定位与差异化分析**（完成后才能进入下一阶段）
   - 一句话价值定位（≤30字）：帮助什么客户，解决什么痛点，获得什么收益
   - 痛点-方案-价值对应表（必须量化）
   - 竞争对手差异化对比表（明确我们的三个不可替代优势）

## 三、商业化落地路径（项目组会前必须输出）

### 1. 定价模式选择（三选一，必须说明理由）

| 定价模式       | 适用场景       | 优势                     | 劣势                         | 我们选择 | 理由 |
|----------------|----------------|--------------------------|------------------------------|----------|------|
| 按项目打包     | 大项目定制     | 单笔金额大，现金流好     | 边际成本高，不可规模化       | ☐        |      |
| 按年订阅       | 标准化产品     | 边际成本低，可规模化，稳定现金流 | 首单金额小，回收期稍长   | ☐        |      |
| 按调用量/数据量 | API服务        | 弹性收费，客户使用门槛低 | 收入波动大，预测难度高       | ☐        |      |

## 四、财务测算（必须量化，财务复核后才能上会）

### 1. 投入测算（6个月产品化阶段）

| 投入项               | 金额（万元） | 计算依据                               |
|----------------------|--------------|----------------------------------------|
| 人力成本             |              | 人数 × 人力月成本 × 月数               |
| 云服务/基础设施      |              | 预计资源消耗                           |
| 第三方服务采购       |              | 如API调用、数据库等                     |
| **总投入**           | **________** |                                        |

### 2. 营收&毛利预测

| 时间段   | 客户数 | 单客ARPU（万元） | 总营收（万元） | 毛利率 | 总毛利（万元） |
|----------|--------|------------------|----------------|--------|----------------|
| 未来1年  |        |                  |                |        |                |
| 未来2年  |        |                  |                |        |                |

**财务逻辑**：
- 毛利率要求：标准化产品≥60%，项目型≥30%，低于这个标准原则上不准立项
- 营收预测必须分客户数×单客ARPU，不能拍脑袋给总数

### 3. 投资回报测算

- 静态回收期：________ 个月（总投入 ÷ 月均净利润）
- ROI（投资回报率）：________ %（累计净利润 ÷ 总投入 × 100%）

**决策依据**：
- 静态回收期≤18个月优先立项
- ROI≥50%优先立项，低于这个标准需要总经理特批

## 五、周会评审决策流程（第5周）

### 评审议题

1. 评审Roadmap可行性：里程碑设置是否合理？资源需求是否匹配？
2. 评审财务测算：投入营收预测是否保守可靠？投资回报符合标准吗？
3. 决策：批准立项 / 调整后重报 / 不予立项

### 本轮输出必须交付

✅ **《核心爆款产品商业计划书》**，包含：

1. 价值定位与差异化分析
2. 6个月产品迭代Roadmap
3. 资源需求清单
4. 商业化路径与财务测算

## 六、立项后跟进机制

- 每月同步进度，偏差超过20%必须重新上会
- 每季度复核财务预测，调整投入产出预期
- 6个月后进行里程碑验收，验收不通过暂停项目
