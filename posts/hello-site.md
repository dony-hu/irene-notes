# 你好，小站

这是一篇测试文章，用来验证新文章发布流程是否正常工作。

## 关于这个小站

这个小站是一个基于 Markdown 的轻量静态个人博客，构建后部署在 Cloudflare Pages 上。

主要特点：

1. **纯 Markdown 写作** - 所有文章都以 Markdown 文件托管在 GitHub，简单纯粹
2. **自动索引** - 构建时自动收集文章信息生成索引，不用手动维护
3. **内外可见性分离** - 公开文章所有人可见，内部文章仅公司飞书用户可访问
4. **支持幻灯片** - 特殊格式可以直接生成幻灯片页面
5. **自动部署** - 推送到 main 分支后自动构建发布

## 测试目的

这篇文章主要测试：

- 新文章创建流程是否顺畅
- 自动构建是否正常工作
- 部署到 Cloudflare Pages 是否成功
- 飞书访问控制是否正常生效
