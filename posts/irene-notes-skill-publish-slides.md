# 技能2：Irene Notes 网页幻灯片发布操作指南
> 适用于发布分享会PPT、产品演示、培训材料等网页版幻灯片，不需要导出PDF，直接在线演示

## 一、核心优势
- 纯Markdown编写，不需要使用PowerPoint/Keynote
- 自动生成响应式网页，支持手机/平板/电脑访问
- 支持演讲者模式、页码跳转、全屏演示等功能
- 提交后自动发布，链接永久有效，不需要上传到第三方平台

## 二、发布步骤
### 1. 创建幻灯片文件
在`posts/`目录下创建Markdown文件，命名规则同普通文章：
```bash
cp posts/TEMPLATE.md posts/g1-product-sharing-202603.md
```

### 2. 配置Front Matter
必须添加`type: webslides`字段，标识这是幻灯片类型：
```md
---
title: G1产品核心优势分享会
date: 2026-03-21
tags:
  - 产品分享
  - 幻灯片
type: webslides
---
```

### 3. 编写幻灯片内容
每张幻灯片以`---`分隔，支持Markdown语法：
```md
# 第1页：封面
## G1产品核心优势分享会
### 2026年3月

---
# 第2页：核心壁垒
## 三大核心竞争力
✅ 自研24级地址引擎
✅ 磐石信创一体机
✅ 端到端结果交付

---
# 第3页：客户价值
## 效率提升10倍以上
以前3个分析师干1天的活，现在输入一句话5分钟出结果
```

### 4. 本地预览验证
执行构建后，会自动生成独立的幻灯片HTML页面：
```bash
npm run build
```
构建完成后访问`http://127.0.0.1:8787/g1-product-sharing-202603.html`即可预览幻灯片效果。

### 5. 提交发布
同普通文章发布流程，提交到main分支后自动部署，线上访问路径为：
`https://irene-notes.pages.dev/[slug].html`

## 三、使用技巧
- 按`F`键进入全屏演示
- 按左右方向键切换页面
- 支持嵌入图片、表格、代码块等内容
- 所有样式自动适配，不需要手动调整格式
