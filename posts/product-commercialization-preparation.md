# 爆款产品立项会前准备输出清单

项目组会前需要输出以下内容，用于周会评审决策：

## 一、产品化改造路径

### 现有能力盘点
- 哪些已经有了可以直接复用？占比多少？
- 哪些需要重新开发？占比多少？

### 6个月 roadmap 拆解

### 资源需求清单
- 需要多少研发工程师？
- 需要多少产品经理？
- 需要多少运营？
- 需要其他事业部什么支持？

## 二、商业化落地路径

### 定价模式选择
对比三种模式选一种，说明理由：

| 模式 | 适用场景 |
|------|----------|
| 按项目打包 | 适合大项目定制 |
| 按年订阅 | 适合标准化产品 |
| 按调用量/数据量 | 适合API服务 |

### 标杆客户开发计划
- 第一个标杆客户找谁？
- 什么时候签下来？
- 怎么突破？
- 需要什么支持？

### 复制扩张路径
- 标杆验证后，怎么复制到行业客户？
- 一年能复制多少家？
- 销售团队需要什么培训/支持？

## 三、财务测算

| 周期 | 投入 | 预计营收 | 毛利 |
|------|------|----------|------|
| 未来1年 |  |  |  |
| 未来2年 |  |  |  |

- 静态回收期：多久能收回投入？
- ROI：投资回报率多少？

## 四、周会讨论决策

**第5周周会讨论点：**

1. 评审 roadmap 可行性，资源需求合理性
2. 评审财务测算，确认投入产出符合预期
3. 决策：批准立项，启动产品化改造

## 本轮输出要求

输出 **《核心爆款产品商业计划书》**，包含：

- 价值定位与差异化分析
- 6个月产品迭代 roadmap
- 资源需求清单
- 商业化路径与财务测算
