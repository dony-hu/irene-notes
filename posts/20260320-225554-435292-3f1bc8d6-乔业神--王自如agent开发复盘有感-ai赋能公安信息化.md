# 王自如Agent开发复盘有感：AI赋能公安信息化的实践与思考

## 一、启发与背景

学习王自如关于AI原生日历与费用管理Agent的开发复盘后，其围绕**"计划与执行"架构**解决传统工具痛点、以AI原生思维重构产品设计的理念，为我参与的公安信息化项目带来了全新的思路启发。

**现状分析**：
- 公安信息化建设正处于从"数字化"向"数智化"转型的关键阶段
- 核心场景痛点：
  - 情指行一体化
  - 110接处警
  - 社区警务
  - 侦查办案
- 存在问题：
  - 交互繁琐
  - 数据孤岛
  - 跨域协同低效

**机遇与挑战**：
- 丰图科技的地址地图能力与AI原生Agent的技术架构相结合，恰好能为这些痛点提供破局方向
- AI时代的技术变革对个人能力提出新要求
- 需清晰自身转型路径、解决转型中的阻碍

---

## 二、AI原生思维下的解决方案

结合公安信息化项目的业务场景、需求痛点与丰图科技的地址地图能力，AI原生思维下的解决方案可实现警务工作从**"人找数据"到"数据找人"**的转变。

### 2.1 传统业务痛点

| 场景 | 痛点 |
|------|------|
| **110接处警** | 民警手动填写多份表单、跨系统调取地址与警力信息 |
| **情指行一体化** | 各警种数据割裂、地址关联精准度低 |
| **社区警务** | 人口、场所信息录入繁琐 |
| **侦查办案** | 需人工梳理地址轨迹、整合多源线索 |

### 2.2 技术能力融合

**丰图科技核心能力**：
- "地址—楼栋—坐标"三位一体空间关系
- CIM+AI时空图谱能力

**AI原生Agent核心能力**：
- 自然语言交互
- 跨域协调
- 计划执行架构

### 2.3 场景化解决方案

#### （1）110接处警场景

```
输入（自然语言）：
"XX路XX小区发生纠纷，调度附近巡逻警力并调取周边监控"

↓

智能体处理流程：
1. 依托丰图地址地图精准定位
2. 自动生成处警计划
3. 联动警力调度、视频监控等系统
4. 完成批量执行
```

#### （2）情指行一体化场景

**技术架构**：
- 采用 **DDD领域驱动设计** 将各警种业务划分为独立域
- 通过**顶层编排器Agent**协调
- 结合丰图的时空位置智能工具
- 实现跨域数据的地址关联与可视化调度

#### （3）侦查办案场景

**能力应用**：
- 借鉴OCR提取与复杂推理能力
- 自动提取案卷中的地址信息
- 依托丰图地图构建嫌疑人行为轨迹
- 实现线索从提取到研判的全链路闭环

#### （4）社区警务场景

**解决方案**：
- 通过自然语言批量录入信息
- 结合地址地图完成人口、场所的精准关联
- 实现动态更新

### 2.4 架构设计

采用**薄客户端架构**：
- **云端**：所有推理与业务逻辑
- **移动警务端**：仅负责渲染展示

**优势**：
- 适配民警户外执法的轻量化需求
- 实现跨平台的快速扩展

## 三、个人能力转型路径

AI时代的警务信息化建设，要求从**技术能力、思维模式、工作方法**三个维度完成全面转型。

### 3.1 技术能力升级

**从传统能力向AI原生能力延伸**：

| 传统能力 | AI原生能力 |
|---------|-----------|
| 软件开发 | AI Agent架构设计 |
| 系统集成 | 大模型微调与落地 |
| - | 丰图地址地图API的集成与二次开发 |
| - | "计划与执行"流水线的搭建逻辑 |
| - | 公安场景的可观测性建设 |
| - | 自动化测试方法 |

### 3.2 思维模式转变

**两个转变**：

1. **摒弃"技术叠加"的伪智能思维，树立"AI原生"的产品思维**
   - 从公安业务场景的真实痛点出发
   - 思考技术与业务的深度融合
   - 而非简单在传统系统上叠加聊天机器人

2. **从单一的技术开发者向"Builder"转型**
   - 既要懂技术架构
   - 也要深入理解情指行、接处警等警务业务的逻辑与需求
   - 实现技术与业务的双向融合

### 3.3 工作方法优化

**借鉴项目中的工程化实践经验**：

| 传统方式 | 优化方式 |
|---------|---------|
| 经验驱动开发 | 数据驱动的工作模式 |
| - | 注重跨域协同的思维培养 |
| - | 以领域驱动设计的思路拆解公安业务 |
| - | 自动化测试融入项目全流程 |
| - | 故障快速定位理念 |

**目标**：提升项目的质量与效率

## 四、转型阻碍与支持需求

在个人转型的过程中，仍存在诸多实际阻碍，需要部门给予针对性的支持与协助。

### 4.1 学习资源匮乏

**问题**：
- 缺乏适配公安信息化的AI Agent开发案例
- 缺乏丰图地址地图与警务系统集成的实战教程

**需求**：
- 统筹引入行业内的优质培训资源
- 邀请技术专家与公安业务骨干开展联合授课
- 搭建内部的技术交流与案例分享平台

### 4.2 跨业务域沟通协作机制不完善

**问题**：
- 公安信息化项目涉及情指、刑侦、社区、交管等多个警种
- 个人难以全面掌握各警种的核心需求

**需求**：
- 建立常态化的业务沟通机制
- 组织技术人员与一线民警开展需求研讨
- 让技术开发更贴合实战

### 4.3 AI开发基础设施与试点环境不足

**问题**：
- 缺乏适配公安场景的Agent SDK
- 缺乏大模型接口调试环境
- 缺乏丰图地址地图与现有警务系统的对接测试环境

**需求**：
- 统筹搭建AI原生开发的技术底座
- 争取更多的项目试点机会
- 让技术成果能在实战中快速验证与优化

### 4.4 传统开发思维固化，缺乏转型激励

**问题**：
- 目前的工作考核与激励机制仍偏向传统系统开发

**需求**：
- 完善激励机制
- 对AI技术落地、业务创新的成果给予认可与奖励
- 鼓励技术人员主动探索AI赋能公安的新路径

AI原生技术的发展为公安信息化建设带来了全新的机遇。

3. 将AI原生思维真正融入公安业务场景

**最终目标**：
- 打造出更贴合实战、更高效便捷的智慧警务解决方案
- 让技术真正成为**提升警务效能、守护社会平安**的核心力量
